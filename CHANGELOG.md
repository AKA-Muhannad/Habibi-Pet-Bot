# Changelog

## 1.0.1

- One-command native macOS installer with checksum validation and source-build fallback.
- Homebrew tap and explicit reinstall-based updates.
- Version selection, custom install directory, and no-launch options.

## 1.0.0

- Floating animated desktop pet with 10 original pixel companions.
- Task activity pill for Claude Code sessions launched through the pet.
- Project folder chooser, Siri launcher, and custom Shortcuts support.
- Universal Apple Silicon/Intel build and packaged installer.
- Manual GitHub release update checks.
